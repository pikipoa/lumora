## 1. はじめに

Lumora（以下「本サービス」）は、利用者が各種AIサービスとの会話などから取り込んだ情報を
保存し、整理するためのサービスです。本ポリシーは、本サービスが取得する情報と、その取り扱いを
説明します。

## 2. 取得・保存する情報

### 2-1. 利用者が本サービスへ取り込む情報

| 種類 | 内容 |
|---|---|
| 会話（Chronicle） | ChatGPT・Claude・Gemini・Perplexity等からエクスポートしたファイルを解析して得られる、会話のタイトルと本文 |
| Markdown／テキスト文書 | 利用者が取り込んだ文書の本文 |
| 開発セッション記録 | Claude Code CLI の記録（`.jsonl`）から復元した本文 |

**エクスポートしたファイルそのものは、利用者の端末内でのみ処理され、当社のサーバーへ
送信されません。**

会話の本文とあわせて、取り込みに関する次の情報も保存されます。

| 種類 | 内容 |
|---|---|
| 取り込み元のファイル名 | アップロードされたファイルの名称 |
| 取り込み元サービス名 | ChatGPT / Claude / Gemini / Perplexity / 文書 / Claude Code の別 |
| 元サービス上の会話ID・日時 | 取り込み元が保持していた識別子と作成・更新日時 |
| モデル名 | 会話に記録されていたAIモデルの名称 |
| 引用元URL | 会話中に含まれていた参照先（Perplexity等） |
| 取り込みの警告・失敗の記録 | 解析できなかった箇所の記録。**対象となった会話のタイトルを含みます** |

### 2-2. 利用者が本サービス上で作成する情報

| 種類 | 内容 |
|---|---|
| Marker | 会話本文から利用者が選択した抜粋、色、位置、前後の文脈、および編集後の本文 |
| Realm | 利用者が作成した分類の名称 |
| Wing | 利用者が作成・承認した章立ての名称とアイコン |
| メモ | 会話やMarkerに対して利用者が記入した文章 |
| 色の意味 | 各色に利用者が付けた呼称と説明 |
| 変更履歴 | Markerの色・状態が変わった記録 |

### 2-3. 本サービスが自動的に生成・記録する情報

| 種類 | 内容 |
|---|---|
| AIによる提案 | Markerに対してAIが提案したタグ・章立ての候補、およびその確度。**Markerへのタグ付け・章立ての割り当ては候補として保存され、利用者が採用または却下するまで確定しません**（ただし、提案されたタグの名称そのものは、候補の作成に伴い保存されます） |
| 利用回数 | AI整理機能の1日あたりの実行回数（本文は含みません） |
| 表示状態 | 機能の解放状況・案内の既読状態 |

### 2-4. アカウント情報

メールアドレスおよびパスワード。認証基盤（後述のSupabase）が管理します。パスワードは
同基盤において暗号化して保管され、当社が平文で参照することはありません。

### 2-5. 自動的に取得される情報

| 種類 | 内容 |
|---|---|
| アクセス記録 | IPアドレス、アクセス日時、利用環境の情報（配信基盤が記録します） |
| 不具合の記録 | エラーの内容、利用者ID、表示していた画面のパス |

### 2-6. 端末内に保存する情報

本サービスは、次の目的で利用者の端末内（ブラウザのローカルストレージ等）に情報を保存します。

- ログイン状態の保持
- 直近に使用したRealmなど、操作を継続するための一時的な情報

これらは**アカウントを削除した際に、あわせて消去されます**。広告目的のトラッキングには
使用しません。

## 3. 情報の利用目的

- 本サービスの機能（保存・検索・整理・表示）を提供するため
- 利用者の求めに応じてAIによる整理の提案を行うため
- 不具合の把握と修正のため
- 過度な利用による費用の急増を防ぐため（利用回数の記録）

**取得した情報を、広告配信や第三者への販売に利用することはありません。**

## 4. 第三者サービスへの提供

本サービスは、以下の外部サービスを利用しています。

| サービス | 提供する情報 | 目的 |
|---|---|---|
| **Supabase** | 2章に記載した情報のすべて | データベース・認証基盤。日本国内（東京リージョン）に保管されます |
| **Anthropic（Claude API）** | **利用者がMarkerとして選択した抜粋、その役割タグ、会話のタイトル、既存の章立ての名称のみ** | AIによる整理の提案 |
| **Sentry** | エラー情報、利用者ID、画面のパス、抜粋の**文字数**（本文は含みません） | 不具合の把握 |
| **Vercel** | アプリの配信に伴うアクセス記録 | 配信基盤 |

### 4-1. Anthropicへの送信について

**会話の全文を送信することはありません。** 送信されるのは、利用者自身がMarkerとして
選択した箇所とその周辺情報だけです。また、送信が発生するのは**利用者が整理機能を明示的に
実行したときに限られます**。取り込んだだけでは送信されません。

**AIモデルの改善への利用について**：当社は、利用する外部AIサービスの提供条件に従って
ユーザー入力データの取り扱いを管理します。2026年7月31日時点で当社が確認した
Anthropicの商用利用規約（Commercial Terms of Service, Section B "Customer Content"）には、
同社が本サービスを通じた顧客コンテンツでモデルを学習しない旨が定められています。
**ただし、これは当社が当該時点の公開規約を確認した事実の記載であり、提供条件が将来変更
される可能性を否定するものではありません。** 変更を把握した場合、本ポリシーを更新します。

### 4-2. 外国にある第三者への提供

**「日本国内に保管される」ことと「データが国外へ出ない」ことは別です。** 本サービスは
データベースを日本国内（東京リージョン）に置いていますが、AIによる整理を実行した際には、
その対象となる情報が**日本国外の第三者へ送信されます**。

| 項目 | 内容 |
|---|---|
| 提供先 | Anthropic（Claude API） |
| 提供する情報 | 4章の表に記載したもの（Markerの抜粋・役割タグ・会話のタイトル・既存の章立ての名称） |
| 提供する場面 | 利用者が整理機能を実行したときのみ |
| **移転先の国** | **特定できていません。** 当社が確認した同社の公開文書には、データが処理・保管される国または地域についての記載がありませんでした（2026年7月31日確認） |
| 移転先国の個人情報保護制度に関する情報 | 上記のとおり国を特定できないため、記載していません |
| 講じている措置 | 送信する情報を利用者が選択した抜粋等に限定していること、および同社の提供条件（4-1）を確認していること |

**移転先の国を推測で記載することはしません。** 確認できていない事実を、確認したかのように
書かないためです。

なお、本サービスが利用する他の外部サービス（Supabase・Sentry・Vercel）についても、
**それぞれの契約主体および設立国は当社として未確認です。** 確認でき次第、本ポリシーへ
反映します。

> **⚠️ 草案段階での留保**：外国にある第三者への提供について法が求める手続（本人の同意を
> 要するか、所定の情報提供で足りるか）は、運営主体の属性や提供先との契約形態によって
> 変わります。**公開前に専門家の確認を受けてください。**

### 4-3. 安全管理措置

当社が実施している措置のうち、確認できている事実は次のとおりです。

- データベースの全テーブルに行レベルセキュリティを適用し、利用者が自身のデータ以外を
  取得できない構成としています
- 不具合監視サービスへは、個人を特定しうる情報の自動収集を無効化した上で送信しています。
  メールアドレスは送信前に除去しています。Markerの本文は送らず、文字数のみを送ります
- 取り込んだファイルの原本は、当社のサーバーへ送信していません

## 5. 保存期間

- **本サービス**：利用者が削除するまで保存します。アカウントを削除した場合、本サービスが
  保有する情報は削除されます（6章）。
- **Anthropic**：2026年7月31日時点で当社が確認した同社の公開情報によれば、API経由の
  入力・出力は原則として受領または生成から30日以内に削除されます。ただし同社の
  利用ポリシー違反の調査対象となった場合（最長2年）、法令上の要請がある場合などの
  例外が定められています。**保存期間は同社の定めに従うため、当社が保証するものでは
  ありません。**
- **Sentry・Vercel**：各サービスの定めに従います。

## 6. 利用者の権利

| 権利 | 方法 |
|---|---|
| **閲覧** | 保存された情報は、すべて本サービスの画面上で確認できます |
| **修正** | Markerの本文・色・範囲、Realm名、Wing名、メモは画面上で変更できます。**取り込んだ原文（引用元）は変更されません**——根拠を辿れるようにするためです |
| **削除** | Markerは個別に取り除けます（記録は履歴として残ります）。会話は保留一覧から完全に削除できます |
| **退会（アカウント削除）** | 設定画面から実行できます。実行すると、本サービスが保有する当該利用者の情報はすべて削除され、**端末内に保存された情報（2-6）も同時に消去されます** |

**現在、データを一括で書き出す機能（エクスポート）はありません。** アカウントを削除すると
内容を取り出せなくなります。この点は削除画面にも表示しています。

なお、アカウント削除後も、既にSentry・Anthropic・Vercelへ送信済みの情報については、
各サービスの定める期間・条件に従って取り扱われます。

### 6-1. 開示・訂正・利用停止等の請求

利用者は、本サービスが保有する自身の個人情報について、開示・内容の訂正・追加・削除・
利用の停止・第三者提供の停止を請求できます。

| 項目 | 内容 |
|---|---|
| 受付方法 | 7章のお問い合わせ先へご連絡ください |
| 本人確認 | 登録されているメールアドレスからのご連絡による確認を行います |
| 手数料 | **（未定。無料とするか、実費を求めるかを決めて記載する）** |
| 回答までの期間 | **（未定。目安を決めて記載する）** |

なお、6章に記載のとおり、多くの操作は本サービスの画面上で利用者自身が実行できます。
