# trust-model.md — Lumoraの信頼境界

**この文書は法律文書ではない。** Lumoraが何を信頼の境界として設計しているかを、
利用者にも分かる形で説明するものである。`EVIDENCE-OS.md`の「振る舞いの憲法」を、
データの扱いという具体に翻訳したものにあたる。

事実の根拠はすべて`docs/data-handling.md`（開発者向け設計契約）にあり、
本文書はそれを言い換えたものである。**両者が食い違った場合は`data-handling.md`が正。**

作成：2026-07-29。

---

## 1. 信頼境界

```
  あなた
    │
    ▼
  Lumora（端末内）        ← エクスポートの原本ファイルはここから出ない
    │
    ▼
  Supabase（東京）        ← あなたの行だけが見える（RLS）。保管は日本国内
    │
────┼──────────────────────────  AI境界
    ▼
  Claude API（国外）      ← 越えるのはマーカーの抜粋だけ
```

**保管は日本国内（東京リージョン）。** ただし「日本に保管される」ことと
「データが国外へ出ない」ことは同じではない。AIに整理を頼んだ時、下の表の左側だけが
国外で処理される。この2つを区別して説明する。

**AI境界の外へ出るのは、あなたがマーカーを引いた箇所だけ。**

| Claude APIへ送るもの | 送らないもの |
|---|---|
| ✓ マーカーの引用テキスト（`quoted_text`） | ✗ 会話の全文 |
| ✓ Roleタグ | ✗ 添付ファイル・エクスポートの原本 |
| ✓ 会話のタイトル | ✗ メールアドレス・アカウント情報 |
| ✓ 既存のTag名（Wing整理時のみ） | ✗ 他の人のデータ |

さらに、AIへ送るのは**あなたが「Knowledge Organize」を押した時だけ**である。
インポートしただけでは何も送られない。

**つまり、AIが読む範囲をあなた自身が決める。** これがLumoraの中心的な設計判断であり、
「チャット全文をAIに渡す」多くのツールとの最大の違いにあたる。

## 2. システムにできること・できないこと

| システムができること | システムができないこと |
|---|---|
| ✓ 検索する | ✗ あなたの知識を消す |
| ✓ 提案する（Tag / Wingの候補） | ✗ 原文を書き換える |
| ✓ 整理を手伝う | ✗ 何が正しいかを決める |
| ✓ 関連を見つける（将来のBeacon） | ✗ 外部へ公開する |

「できないこと」は実装上の未対応ではなく、**設計上の制約**である。根拠：

- **消さない** — `PRINCIPLES.md` Principle 3。ただしこれは**システムへの制約**であり、
  あなた自身の削除を妨げるものではない（3章）
- **原文を書き換えない** — `quoted_text`はマーカーを引いた瞬間に固定され、以後不変。
  編集した文章（`edited_text`）は別に持つ（`PRINCIPLES.md` Principle 4）
- **正しさを決めない** — AIは候補を出すだけで、採用も却下もあなたが決める
  （`PRINCIPLES.md` Principle 1）

## 3. 削除について

**「知識は破壊しない」は、システムがあなたの知識を勝手に捨てないという約束であって、
あなたが消せないという意味ではない。**

- マーカーを外す、Wingから外す — 記録は残る（後から辿れるようにするため）
- 保留一覧からの「完全に削除」 — 実際に消える
- **アカウントの削除** — **設定画面から実行できる（2026-07-31）**

アカウントを削除すると、Supabase上のあなたのデータは**すべて**消える。端末内のキャッシュも
同時に消える。削除の前に、何が消えるか（Chronicle / Arca / Realm の件数）を表示する。

**ただし、現在データのエクスポート機能はない。** 削除すると内容を取り出せなくなる。
「いつでも離れられる」と言う以上これは不足であり、隠さずに削除画面にも明記している。
Phase2で対応する。

## 4. まだ答えられていないこと

信頼は「できている部分だけ書く」ことでは得られないため、未整備の項目も明示する。

| 項目 | 状態 |
|---|---|
| データのエクスポート | **未実装**（削除はできるが持ち出せない。Phase2で対応） |
| エラー監視（Sentry）のリージョン | **未確認** |
| データの保持期間 | **未定義** |
| AI提供元の学習利用に関する規約確認 | **未実施**（規約の該当箇所を確認し、確認日を記録する） |
| プライバシーポリシー・利用規約 | **未作成** |

これらは`docs/data-handling.md`に同じ内容が記録されており、解消のたびに両方を更新する。
